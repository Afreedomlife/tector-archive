Terms of Use

Effective date: 12 October 2026 · Maintained by the Afreedomlife GitHub account

TECTOR Archive is an owner-operated utility for backing up selected personal game-development files to the owner's own Google Drive account. It is not a public file-hosting service, cloud storage provider, or Google product.

Permitted use

The public website provides information about the intended local workflow. The workflow uses the third-party open-source rclone program, which is governed by its own license and documentation. No external user accounts or hosted backup service are offered by this website.

Data and permissions

The owner decides which local files to copy and which Google Account to authorize. Permission requests are shown by Google OAuth. See the Privacy Policy for the drive.file scope, how credentials are handled, how to revoke access and how to delete cloud copies.

Backup responsibility

The owner should verify uploaded files and test restoration before removing any local originals. A successful upload alone does not guarantee recoverability. Local removal, if any, is a separate, explicitly authorized step. This site is offered as-is without guarantees of continuous availability.

No affiliation

TECTOR Archive is independent and is not endorsed by Google, GitHub or the rclone maintainers. Google Drive, GitHub Pages and rclone are separate services with their own terms.

Contact

For questions about these public pages, use GitHub Issues. Issues are public: do not include passwords, tokens, private file paths or personal data.
