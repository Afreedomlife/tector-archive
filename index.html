Independent backup workflow

Keep the work. Free the workspace.

TECTOR Archive is a small, owner-operated workflow for backing up selected TECTOR game-development files—such as renders, test videos, reports and project snapshots—from a local Windows PC to the owner's Google Drive using rclone.

1. Select files

The owner chooses specific folders and files on their own computer. Nothing is uploaded just by visiting this site.

2. Authorize Drive

The rclone desktop client uses Google OAuth with the drive.file scope to create and manage files that the app is permitted to access.

3. Copy, do not sync-delete

The planned backup workflow uses copy-only operations. Local original files remain intact. Destructive cleanup requires separate manual approval.

4. Verify backups

The owner verifies upload results, checks backup manifests and tests restoration before considering any local-space recovery.

What this website does not do

  • It does not authenticate users, offer cloud storage accounts, or request access to Google Drive itself.
  • It does not collect files, OAuth credentials, personal information, payment data or analytics.
  • It does not publish the TECTOR game code, assets or backup contents.
  • It is not affiliated with, endorsed by or operated by Google or the rclone project.

Google Drive access

This personal setup requests the Google Drive API scope https://www.googleapis.com/auth/drive.file, which limits access to Drive files the app creates or is specifically authorized to access. The Google consent screen displays the permission requested. Tokens are kept on the owner's device by rclone, not by this website. Review the Privacy Policy for details, retention and revocation.

Security: Never enter your Google OAuth client secret, access token, or TECTOR files into this public website or its GitHub issue tracker.

Help and contact

Questions about the public information pages can be raised through GitHub Issues. Issue threads are public; do not post credentials, personal data or private file names. For rclone technical guidance, see the official Google Drive documentation.
